Download Master is a robust, user-friendly file downloading application developed using Java and JavaFX. It offers a comprehensive set of features designed to simplify and enhance the file downloading experience:
Key Features:

 Graphical User Interface: A clean and intuitive interface that allows users to easily manage their downloads, including viewing all active downloads in a table format.
 File Downloads: Supports downloading files from the internet via URL with options to pause, resume, and cancel downloads.
 Multi-threaded Downloads: Enables simultaneous downloads of multiple files, enhancing efficiency and reducing wait times.
 Error Handling: Provides robust error handling for scenarios such as connection loss or unavailable files, ensuring downloads can recover smoothly.
 Settings Configuration: Users can customize download settings, including specifying the download directory and configuring proxy server settings for added flexibility.
 Notifications and Alerts: Real-time alerts notify users upon completion of downloads or if an error occurs, keeping them informed at all times.
 Export/Import Download Lists: Allows exporting the list of downloads to CSV or JSON format for future use, as well as importing download lists to continue where you left off.

Non-functional Highlights:

 Designed to be responsive and performant, with no lag during active downloads.
 Built for compatibility with Java versions 8 and above.
 Developed with clean, well-structured code, accompanied by comprehensive documentation and in-line comments for maintainability.

Java Download Master is ideal for users looking for a reliable and feature-rich solution to manage their file downloads effortlessly. Whether for personal or professional use, this application aims to streamline the download process, providing a seamless and efficient user experience.
